# Smart-Term 实现设计说明（中文）

## 1. 文档目标

本文档描述 Smart-Term（Electron 版本）当前最终实现方案，包括架构分层、核心流程、数据模型与关键工程决策。

## 2. 产品范围

Smart-Term 当前聚焦以下能力：

- 本地终端与 SSH 终端多标签会话
- 双面板 SFTP 传输（本地/远程、远程/远程）
- 传输队列、进度、失败重试、冲突策略
- SSH 配置管理与凭据安全存储
- 会话保存/恢复、命令历史、审计日志
- 中英文界面切换

## 3. 最终技术栈

- **运行时**：Electron
- **终端渲染**：xterm.js
- **本地 PTY**：node-pty
- **SSH/SFTP**：ssh2
- **桥接层**：preload + IPC
- **持久化**：
  - `app.getPath('userData')` 下 JSON（设置/历史/审计等）
  - `keytar`（系统钥匙串）
  - 钥匙串不可用时使用兼容 fallback 存储

## 4. 运行时架构

### 4.1 主进程（`src/main.js`）

职责：

- 本地 PTY 生命周期管理
- SSH/SFTP 会话管理
- 传输执行与进度事件
- 设置/历史/审计持久化
- 安全能力（主机信任、凭据存储）

关键决策：

- SSH 会话按标签独立建模（`sessionId -> session`）
- 当前活动标签决定终端输出路由
- 切换标签不销毁其他 SSH 会话

### 4.2 Preload（`src/preload.js`）

职责：

- 对 renderer 暴露最小必要 API
- 隔离 renderer 与 Node.js 直接访问
- 提供事件订阅（`onData`、`onStatus`、传输进度等）

### 4.3 渲染层（`src/renderer.js` + `src/index.html`）

职责：

- 页面状态与标签管理
- SSH 配置增删改查与连接流程
- 双面板文件浏览与拖拽交互
- i18n 文案渲染与运行状态提示

关键决策：

- 每个标签保存独立终端输出缓冲
- 标签切换时恢复该标签内容，而非全局清屏
- 主题切换/标签恢复时强制同步终端尺寸

## 5. SSH 会话模型

### 5.1 会话隔离

- 每次 SSH 连接返回唯一 `sessionId`
- 标签保存并使用自身 `sessionId`
- 切回标签优先 `activateSSH(sessionId)`
- 关闭标签仅断开该标签对应会话

### 5.2 断开与重连

- 手动断开只作用于当前标签会话
- 快速重连会先清理当前标签会话再重建
- 标签间切换不应触发其他会话被替换

## 6. 双面板 SFTP 设计

### 6.1 交互模型

- 左右面板可独立连接本地或 SSH
- 支持：
  - 本地 -> 远程
  - 远程 -> 本地
  - 远程 -> 远程
  - 本地 -> 本地

### 6.2 已实现交互优化

- 面板配置下拉支持自动连接
- 文件列表附近放置“上级/刷新”操作
- 新增路径直达输入（如 `/tmp` + 回车）
- 传输进度弹窗居中显示
- 窄窗口下工具栏响应式重排

### 6.3 传输可靠性

- 队列化执行
- 冲突策略：覆盖 / 跳过 / 重命名
- 失败项列表与单项/批量重试
- 中断任务恢复

## 7. 凭据与安全策略

- 优先使用 `keytar` 保存 SSH 凭据
- 无钥匙串环境自动启用 fallback 存储
- 连接时自动读取已保存密码/私钥/口令
- 首连主机指纹确认与 known_hosts 信任校验

## 8. 国际化（i18n）

- 语言：`zh-CN`、`en-US`
- 静态与动态文案均通过词条管理
- 连接/传输状态提示支持双语
- 语言切换时刷新关键控件文案

## 9. 持久化数据概览

位于用户数据目录：

- settings
- command history
- audit logs
- SSH profiles（非敏感字段）
- known hosts
- 凭据 fallback 文件（仅兼容场景）

## 10. 当前约束

- 标签恢复为缓冲回放，不是 PTY 完整状态快照
- 长时间会话会对本地缓冲做截断以控制内存
- fallback 凭据存储仅为兼容方案，不作为首选安全方案

## 11. 后续优化方向

- 终端滚动缓冲跨重启持久化
- fallback 凭据加密增强
- shell integration 可视化（命令边界 + cwd 时间线）
- 面向标签粒度的资源监控与命令智能分析

### 12.2 SSH 多标签会话图（同主机互不干扰）

```text
┌─────────────────────────────────────────────────────────────────────┐
│                   SSH 多标签会话（同主机互不干扰）                 │
├─────────────────────────────────────────────────────────────────────┤
│ 1) 新建标签 A 并连接                                                │
│    Renderer ──connectSSH(A)──▶ Main ──▶ 建立 Session A             │
│    Main ──sessionId:A──▶ Renderer                                  │
│                                                                     │
│ 2) 新建标签 B（同 host）并连接                                      │
│    Renderer ──connectSSH(B)──▶ Main ──▶ 建立 Session B             │
│    Main ──sessionId:B──▶ Renderer                                  │
│                                                                     │
│ 3) 切换回标签 A                                                     │
│    Renderer ──activateSSH(sessionId:A)──▶ Main                      │
│    Main 将 Session A 设为 active（Session B 保持在线）              │
│                                                                     │
│ 4) 关闭标签 A                                                       │
│    Renderer ──disconnectSSH(sessionId:A)──▶ Main                    │
│    Main 仅断开 Session A；Session B 不受影响                        │
└─────────────────────────────────────────────────────────────────────┘
```
